💀 GitHub Graveyard

«Give your abandoned code a proper funeral.»

GitHub Graveyard is a tool that digs through your GitHub repositories, finds the projects you've abandoned, and gives them the funeral they deserve.

Enter a GitHub username, exhume the repositories, and discover which projects are dead, ghosted, or barely alive.

⚰️ What It Does

- 🔎 Analyzes public GitHub repositories
- 💀 Identifies abandoned projects
- 🪦 Generates a personalized digital graveyard
- 📜 Creates shareable grave cards for dead repositories
- 🔗 Lets you share your graveyard with others
- 💾 Download your grave cards
- 🔐 Optional wallet connection
- ⛓️ Bury a project permanently on-chain
- 🖼️ Mint an on-chain memorial for your dead repository

⛓️ Web3

GitHub Graveyard doesn't require a wallet to use.

The entire graveyard experience is available without Web3.

For users who want to make a project permanent, GitHub Graveyard provides an optional Bury On-Chain experience.

A buried project can receive a permanent on-chain memorial containing information about the grave, such as:

- Repository
- GitHub username
- Date of burial
- Grave ID
- Grave metadata

The goal is simple:

«Your code may be abandoned. Its grave doesn't have to be.»

🚀 Run Locally

Clone the repository:

git clone https://github.com/YOUR-USERNAME/Github-Graveyard.git

Open the project folder:

cd Github-Graveyard

Then open "index.html" in your browser.

No complicated setup required.
